TreeSet-> uses self-balancing tree(red-black tree) internally

tree traversal: 
-inorder(LNR)
-preorder(NLR)
-postorder(LRN)

treeSet methods:
-add()
-remove()
-contains()
->first()
->last()
->ceil()  \\[10,20,30,40,50]
checks highest-> ceil(25)=30
->floor()
checks lowest->floor(25)=20
-higher()
-lowest()

Map Interface:

storing in key(unique)-value(can store duplicates) pairs
    ex: studenid-name
        100-A 
        101-B
        102-C 
    ->  map<Integer,String>

HashMap:
->hashcode() & equals()

methods:
-map.put(0,1)(to add and update)
        key,value
map.put(0,2)
    if key exist value will update

-map.get(key)->retrieves the value

-containskey(0)-> returns true if key exists else false

-map.remove(key)->removes the key

-map.getorDefault(0,1)
ex:map.put(1,map.getorDefault(1,0)+1)
